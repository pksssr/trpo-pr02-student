## Что сделано

Страница каталога из 18 карточек товаров. Есть шапка, панель фильтров, информационный блок, область карточек и подвал. Раскладка построена на CSS Grid и Flexbox, стили написаны на SCSS и собираются в `css/styles.css`. Фильтры сделаны на уровне разметки и стилей (JavaScript в работе не используется).

## Структура проекта

```
trpo-pr02-student/
├── index.html
├── css/styles.css          # результат компиляции SCSS
├── scss/
│   ├── styles.scss         # главный файл, подключает остальные части
│   ├── _variables.scss     # переменные: цвета, радиус, интервалы, ширина контейнера, breakpoint'ы

│   ├── _base.scss          # сброс и базовые стили
│   ├── _layout.scss        # шапка, раскладка Grid, сетка карточек, подвал
│   └── _components.scss    # фильтры, кнопки, информационный блок, карточка
├── data/
│   ├── catalog.csv
│   └── theme.json
├── images/product-01.svg … product-03.svg
├── package.json
└── README.md
```

## Как собрать CSS из SCSS

Нужен установленный Node.js. Один раз в папке проекта:

```
npm install
```

Разовая сборка:

```
npm run build
```

Режим наблюдения (пересобирает CSS при каждом сохранении SCSS):

```
npm run watch
```

Эти команды запускают `sass scss/styles.scss css/styles.css`. Скомпилированный `css/styles.css` лежит в репозитории, поэтому для просмотра страницы достаточно открыть `index.html`.

## Что где применено

- **Переменные SCSS**: цвета, радиус, интервалы, ширина контейнера, точки перелома (`scss/_variables.scss`).
- **Mixin**: `container` (адаптивный контейнер), `focus-ring` (состояние фокуса), `respond($max-width)` (media query). Находятся в `scss/_mixins.scss`, используются в `_base.scss`, `_layout.scss`, `_components.scss`.
- **Функции**: `rem($px)` переводит пиксели в rem, `space($n)` умножает базовый интервал `$space`.
- **Вложенность**: не глубже двух уровней (например, `.product-card { &__body { … } }`).
- **Grid**: раскладка `.catalog-layout` (панель фильтров 16rem + каталог) и сетка карточек `.products` (`repeat(auto-fill, minmax(…))`).
- **Flexbox**: шапка, информационный блок, мета-строка карточки, кнопки фильтров.

## Breakpoint'ы

| Ширина | Что меняется |
| --- | --- |
| до 960 px | основная раскладка в одну колонку: фильтры над каталогом |
| до 560 px | карточки становятся плотнее: меньше отступы, колонки подбираются по ширине (2 колонки на 375 px) |

Проверено в DevTools Responsive Mode на ширинах 375, 768 и 1440 px: горизонтальной прокрутки нет.

## Чем переменная SCSS отличается от CSS custom property

Переменная SCSS (`$accent`) существует только на этапе компиляции: Sass подставляет значение и в итоговом CSS её уже нет. Менять её в браузере нельзя. CSS custom property (`--accent`) остаётся в итоговом CSS, браузер читает её во время работы, и её можно переопределить для отдельного блока или изменить через JavaScript.

## Зачем нужны partial-файлы

Partial — это SCSS-файл, имя которого начинается с подчёркивания (`_base.scss`). Он не превращается в отдельный CSS, а подключается в главный файл через `@use`. Это позволяет разделить стили по назначению (переменные, базовые стили, раскладка, компоненты) и не держать всё в одном длинном файле.

## Сравнение SCSS и CSS

В `css/styles.css` нет переменных, mixin'ов и вложенности: Sass подставил значения, раскрыл `&__title` в `.card__title`, вынес media query наружу и посчитал функции (`rem(256px)` стало `16rem`).
